          Ordem do script gerado
        

        
O script PostgreSQL é montado em seções, na ordem usada pelo pg_dump:
          remoção de tabelas → tabelas → comentários → dados → índices → sequências → chaves estrangeiras.
          Assim ele roda do início ao fim mesmo que o MySQL tenha as tabelas em outra ordem.
